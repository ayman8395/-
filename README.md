# 📱 تطبيق نظام الإرشاد النفسي - Guidance Counseling System

## نظرة عامة
تطبيق أندرويد متقدم لنظام الإرشاد النفسي والتدخل السريع في حالات الطوارئ، مع دعم كامل للعربية ويستخدم تقنيات **Cognitive Behavioral Therapy (CBT)**.

### الميزات الرئيسية:
✅ **إدارة دراسات الحالة**: حفظ وتنظيم بيانات الطلاب بشكل آمن
✅ **محرك التشخيص الذكي**: أسئلة تشخيصية سريعة وفعالة
✅ **توليد خطط العلاج**: خطط CBT مخصصة بناءً على الأعراض
✅ **تشفير البيانات**: حماية كاملة للبيانات الحساسة
✅ **واجهة عربية كاملة**: دعم كامل للغة العربية
✅ **قاعدة بيانات محلية**: عمل بدون اتصال إنترنت

## الاستخدام الأساسي

### إضافة حالة جديدة
1. اضغط على "إضافة حالة جديدة"
2. أدخل معلومات الطالب
3. اضغط "حفظ"

### إجراء التشخيص
1. اختر الحالة من القائمة
2. أجب على الأسئلة التشخيصية
3. سيتم توليد خطة العلاج تلقائياً
4. اضغط "حفظ الخطة"

## الحالات السريرية المدعومة

### 1. الصدمات والقلق الحاد (PTSD)
- الكوابيس المتكررة
- السلوكيات الارتدادية
- الالتصاق غير الطبيعي

### 2. السلوك العدواني
- العنف الجسدي واللفظي
- التخريب المتعمد
- نوبات غضب حادة

### 3. الانسحاب الاجتماعي
- العزلة التامة
- فقدان الشغف
- الحزن الدائم
